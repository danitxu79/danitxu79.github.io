*   **Hardware:** Sustitución de PC 486 obsoleto por **Raspberry Pi PLC (Industrial Shields)**.
*   **Software:** Desarrollo íntegro en **Python** (Tkinter) con hilos asíncronos para lectura de sensórica en tiempo real.
*   **Innovación:** Implementación de algoritmos dinámicos de dosificación de agua basados en temperatura y humedad (vía Arduino/USB).
