CobolWorks

Entorno de Desarrollo Integrado (IDE) moderno diseñado específicamente para revitalizar el mantenimiento y la migración de sistemas heredados de COBOL.

Descripción Técnica

CobolWorks ofrece una interfaz potente y moderna para desarrolladores COBOL, facilitando el análisis de código antiguo y la depuración visual. Su característica más innovadora es la integración con la API de Gemini para asistir en la traducción automática de rutinas críticas a lenguajes modernos como Python y Java.

Características Principales

  • Análisis de Flujo Interactivo: Visualiza en tiempo real los árboles de ejecución PERFORM y GO TO para entender la lógica del programa de un vistazo.
  • Depuración Visual Avanzada: Interfaz gráfica para GDB/LLDB con gestión de puntos de interrupción con un solo clic en el margen.
  • Integración con IA: Traduce automáticamente bloques de código COBOL a Python o Java utilizando modelos de lenguaje avanzados.
  • Editor Inteligente: Resaltado de sintaxis para múltiples dialectos (IBM, Micro Focus, GnuCOBOL), IntelliSense y navegación rápida por Copybooks.
