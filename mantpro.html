MantPro

MantPro es un sistema profesional de gestión de mantenimiento (GMAO) diseñado para equipos industriales y flotas de vehículos. Ofrece una solución integral que combina una potente aplicación de escritorio con una aplicación móvil sincronizada.

Descripción Técnica

El sistema utiliza una arquitectura híbrida: la aplicación de escritorio está construida con Python y PyQt6, integrando un servidor Flask para la sincronización. La aplicación móvil está desarrollada con Flutter para garantizar una experiencia fluida en Android.

Características Principales

  • Gestión de Calendario: Visualización intuitiva de tareas preventivas con códigos de colores por prioridad y estado.
  • Sincronización Móvil: Los técnicos pueden registrar intervenciones en campo desde la App móvil mediante códigos QR.
  • Informes Profesionales: Generación automática de reportes en PDF con logotipos personalizados y detalles técnicos.
  • Gestión de Activos: Base de datos completa para vehículos, maquinaria, clientes y ubicaciones.
  • Modo Offline: La App móvil permite trabajar sin conexión y sincronizar los datos automáticamente al recuperar el acceso al servidor.
